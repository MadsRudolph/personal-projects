Detailed Description

5x7 pixel monospace font stored in AVR PROGMEM.

Covers ASCII 32 (space) through 126 (~): 95 characters, 5 bytes each (475 bytes total). Each byte encodes 5 columns of 7 vertical pixels, LSB = top pixel.

Usage:

uint8_t col_data = pgm_read_byte(&font5x7[(c - 32) * 5 + col]);
