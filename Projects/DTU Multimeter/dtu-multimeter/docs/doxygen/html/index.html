DTU Digital Multimeter — Firmware Reference

What Is This?

This is the firmware for a Fluke 289-class digital multimeter built on an ATmega2560 (Arduino Mega 2560) using bare-metal AVR C — no Arduino framework.

It supports 22 measurement modes (voltage, current, resistance, capacitance, frequency, temperature, oscilloscope, and more), an OLED display, data logging, and a serial command interface.

Module Groups

The firmware is organized into layers. Click any group to see its functions and defines.

Hardware Drivers** (talk directly to chip registers):

  • SPI Master Driver — SPI bus (MCP3208 ADC)
  • I2C (TWI) Master Driver — I2C bus (OLED, RTC)
  • UART0 Serial Driver — Serial port (PC communication)

  • Timer / Tick Driver — System tick, microsecond timing, frequency capture

    Peripheral Drivers** (control external chips):

  • MCP3208 12-bit ADC — MCP3208 12-bit ADC with oversampling
  • Multiplexer & Analog Switches — 74HC4067 mux, CD4053 switches, current source, cap charge
  • SSD1306 OLED Display Driver — SSD1306 OLED framebuffer and drawing functions

  • DS1307 Real-Time Clock — DS1307 real-time clock

    Application Logic** (what makes it a multimeter):

  • Measurement Engine — 22 measurement mode implementations
  • Auto-Ranging State Machine — Auto-ranging state machine
  • True-RMS Computation — True-RMS computation engine
  • Oscilloscope — 1000-sample oscilloscope
  • User Interface — Buttons and serial command interface
  • Display Renderer — Fluke-style OLED screen layout

  • Data Logging — EEPROM circular buffer data logger

    Configuration:**

  • Configuration — All pin definitions, calibration constants, and enums

Serial Commands

Connect at 115200 baud, 8N1. Type ? for a help listing.

Key Action
M Cycle measurement mode
R Toggle relative (delta) mode
H Toggle display hold
A Toggle min/max recording
L Toggle data logging
G Dump logged data as CSV
K Clear log buffer
+ / - Range up / down (locks auto-range)
Z Zero (reset to auto-range)
P Print current reading
E Toggle low-pass filter
? Show help

Building

Requires PlatformIO:

cd dtu-multimeter
pio run # compile
pio run -t upload # flash to Mega 2560
pio device monitor # open serial terminal

Calibration

After building, measure your board's actual 5 V rail and update V_REF in config.h. Then measure each reference resistor with a known-good meter and update RREF_0 through RREF_7. See the Build Guide for a full walkthrough.
