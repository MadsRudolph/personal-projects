Detailed Description

Oscilloscope module for the ATmega2560 DTU multimeter.

Provides 10-bit ADC waveform capture with triggering, automatic measurements (Vpp, Vrms, frequency, duty), OLED rendering, ASCII waveform output, and binary dump for the Python GUI.
